## 🚀 About This Project

A **high-performance**, sleek portfolio website built with **React + Vite + TypeScript**. Featuring a sophisticated dark/light theme system, smooth animations, and optimized loading for the best user experience.

![Portfolio Preview](./public/preview.png)

---

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 🎨 **Dual Theme System** | Seamless dark/light mode with CSS variables |
| 🖱️ **Custom Cursor** | Miro-style interactive cursor with hover effects |
| ⚡ **Lightning Fast** | Code splitting, lazy loading & service worker caching |
| 📱 **Fully Responsive** | Mobile-first design with optimized breakpoints |
| 🎭 **Smooth Animations** | Intersection Observer & CSS transitions |
| 🎯 **Performance Optimized** | Content-visibility, preloading & chunk splitting |
| 🍔 **Mobile Navigation** | Elegant hamburger menu with backdrop blur |
| 📜 **Project Showcase** | Interactive project cards with gradient effects |

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/H3m0rv1ch1/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

### Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |

## ⚡ Performance Highlights

- ✅ **Code Splitting**: Below-fold components lazy-loaded
- ✅ **Service Worker**: Offline asset caching
- ✅ **Font Optimization**: Preconnect + font-display: swap
- ✅ **Image Preloading**: Critical images fetchpriority="high"
- ✅ **CSS Optimization**: Content-visibility for off-screen sections
- ✅ **Bundle Analysis**: Manual chunk splitting for vendor libraries
- ✅ **Reduced Motion**: Accessibility support
